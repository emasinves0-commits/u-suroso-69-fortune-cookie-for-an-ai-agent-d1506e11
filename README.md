One crisp fortune-cookie line, written for an AI agent — in classic
fortune-slip voice, with the luck turning out to be a token saved by an
aborted prompt.

## Entry

> Your lucky number is the token you nearly spent when the user typed "never mind".

## Run

```sh
node main.ts
```

Writes the exact line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`),
with no trailing newline. The line is byte-guarded to 1–140 bytes.
